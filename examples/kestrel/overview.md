# Project Kestrel: overview

Project Kestrel replaces the legacy badge-reader integration at the Tacoma warehouse.
The project owner is Priya Nair. The executive sponsor is Marcus Oyelaran.

- Go-live date: 2026-12-03
- Budget: 184,000 USD, of which 61,500 USD is already spent
- Pilot site: Tacoma warehouse, dock doors 4 through 9
- Vendor: Halcyon Access Systems (contract HAS-7731)

The cutover plan runs overnight. Badge readers on docks 4-9 are swapped first, then the
controller firmware is upgraded, then the old integration is switched off.
